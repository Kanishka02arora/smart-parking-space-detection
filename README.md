# Smart Parking Space Detection and Occupancy Monitoring Using Computer Vision

A VITyarthi BYOP Computer Vision project designed for real-time parking space detection and occupancy tracking.

## Directory Structure

```
smart-parking-space-detection/
├── src/
├── tests/
├── data/
├── requirements.txt
├── README.md
├── statement.md
└── .gitignore
```

## Setup Instructions

1. Clone or navigate to the project root directory.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
